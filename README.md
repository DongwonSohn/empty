# 仄か · 밤의 기록

A personal night music website inspired by Eve’s 「夜は仄か」.

This repository contains a static website, ready for GitHub Pages. Choose **Deploy from a branch**, **main**, and **/ (root)** in **Settings → Pages**.

Open `index.html` to preview locally. Notes and favorites are saved only in the current browser. Rain audio starts after pressing the rain button. Google Fonts and the official YouTube video require an internet connection.

The illustration and example journal entries were created for this unofficial personal website.
