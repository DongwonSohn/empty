# 仄か · 밤의 기록

A personal night music website inspired by Eve’s 「夜は仄か」.

## Live sites

- Primary website: https://www.linthesiagame.com/
- GitHub Pages: https://dongwonsohn.github.io/empty/

## Automatic deployment

Changes pushed or merged into `main` automatically deploy to the existing Vercel project `linthesiagame` and update `www.linthesiagame.com`. GitHub Pages also publishes from `main` at the repository root.

The site is plain HTML, CSS, and JavaScript. Vercel uses the **Other** framework preset, no install/build command, and output directory `.`.

## Local use

Open `index.html` to preview locally. Notes and favorites are saved only in the current browser and are separate for each website address. Rain audio starts after pressing the rain button. Google Fonts and the official YouTube video require an internet connection.

The illustration and example journal entries were created for this unofficial personal website.
